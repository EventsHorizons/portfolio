# 06. Mapa de Palabras Clave y Estrategia de Intención de Búsqueda

---

## 1. Clasificación de la Intención de Búsqueda

Para posicionar a Germán Andrés Gómez, la estrategia SEO se organiza en tres niveles de intención:

### Nivel 1: Búsqueda de Marca Personal y Nombre Propio (Branded Keywords)
Son búsquedas de reclutadores o clientes que ya conocen o escucharon su nombre tras recibir un currículum o ver una postulación:
- `Germán Andrés Gómez`
- `Germán Gómez Colmenares`
- `Andrés Gómez desarrollador web`
- `Germán Gómez portafolio`
- `Germán Gómez UNP`
- `Andrés Gómez frontend Bogotá`

**Objetivo:** Dominar los resultados 1 a 3 de Google con el sitio web oficial, el perfil de LinkedIn y el perfil de GitHub, evitando confusión con homónimos.

### Nivel 2: Búsqueda de Contratación y Talento Técnico (Commercial / Hiring Intent)
Son búsquedas realizadas por reclutadores IT, directores de tecnología y agencias buscando perfiles específicos en la región:
- `Desarrollador frontend Bogotá`
- `Frontend engineer Bogotá`
- `Desarrollador React Bogotá`
- `Desarrollador Angular Colombia`
- `Desarrollador Next.js Colombia`
- `Programador frontend Colombia`
- `Diseñador UI/UX desarrollador web Bogotá`

**Objetivo:** Indexar en páginas de resultados locales mediante optimización on-page en el portafolio y perfiles de empleo vinculados.

### Nivel 3: Búsqueda de Servicios y Productos Digitales (Consultoría / Freelance)
Búsquedas de fundadores y empresas medianas que buscan soluciones directas:
- `Desarrollo de páginas web modernas Bogotá`
- `Diseño de sistemas de diseño en Figma y React`
- `Consultor de interfaces web Colombia`
- `Optimización de rendimiento web Core Web Vitals Bogotá`

## 2. Inserción Estratégica en el Portafolio (On-Page SEO)

| Término Clave | Ubicación On-Page | Justificación Técnica |
| :--- | :--- | :--- |
| **Frontend Engineer & Digital Product Developer** | `<title>`, `<h1>` meta-eyebrow, Schema.org | Posiciona el rol exacto sin inflar antigüedad. |
| **Bogotá, Colombia** | Schema.org Address, `<aside class="print-header">`, Footer | Georreferenciación indispensable para búsquedas locales en Colombia. |
| **React, Next.js, Angular 17+, TypeScript** | Hero chips, Marquee, Sección Stack, Project cards | Palabras clave tecnológicas indexables requeridas por bots de reclutamiento. |
| **Sistemas de Diseño & UI/UX** | Sección Criterio, Meta chips, Schema.org | Atrae a empresas que buscan programadores con criterio estético. |
| **Unidad Nacional de Protección (UNP)** | Trayectoria profesional, Schema.org `worksFor` | Aporta autoridad gubernamental verificable y reputación de ciberseguridad. |
