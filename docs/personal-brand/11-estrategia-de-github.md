## 2. Estandarización de READMEs en los Repositorios

Para que un repositorio genere credibilidad técnica ante un Tech Lead, debe contar con 5 secciones indispensables:
1. **Badges:** Tecnologías, licencia, estado del despliegue.
2. **Contexto del Problema y Arquitectura:** Explicar qué resuelve el software y cómo está estructurado.
3. **Demostración Visual:** GIF o captura de pantalla de alta fidelidad.
4. **Instrucciones de Instalación Local:**
   ```bash
   git clone https://github.com/EventsHorizons/nombre-repo.git
   cd nombre-repo
   npm install
   npm run dev
   ```
5. **Decisiones de Ingeniería Clave:** Por qué se eligió cierta librería o cómo se mitigó un problema de rendimiento.
